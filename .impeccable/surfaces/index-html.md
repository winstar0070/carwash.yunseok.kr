# index.html Surface Brief

## Scope and Mode
- Target: src/client/index.html
- Mode: Operate
- Audience: 세차장에서 물 용량을 기준으로 원액을 계량하는 사용자.

## Direction contract
- THESIS: 물 용량과 희석비율을 입력해 필요한 원액을 바로 확인한다.
- OWN-WORLD: 사용자 지정 흰 배경과 검은 글자, 무채색 입력창, 얇은 구분선, 작은 모서리.
- STORY: 물 용량 → 희석비율 → 넣을 원액 → 저장한 비율.
- FIRST VIEWPORT: 입력 두 가지와 계산 결과를 우선 배치한다. 계량 보조 정보는 기본 접힌 상태로 제공한다.
- FORM: 최대 너비 720px의 한 열 계산기. 중첩 카드나 상태 배지 없이 여백으로 구분한다.
- FINISH: 데스크톱과 모바일 화면, 계산, 단위 전환, 저장 목록을 실제 브라우저에서 확인한다.
