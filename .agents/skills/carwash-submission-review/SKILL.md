# 세차 계산기 제출 검토

- 먼저 AGENT.md와 README.md를 읽고, 화면 변경이 있으면 DESIGN.md도 확인한다.
- 최초 계획 원본이 없으면 초기 커밋에서 확인되는 기능을 재구성한 것이라고 밝힌다. 커밋 날짜를 push 날짜나 실제 실습 제출일로 표현하지 않는다.
- 물을 먼저 받는 기준을 유지한다. 원액:물 = 1:N이면 원액 ml = 물 ml / N이다. 완성액 원액 농도 c%이면 원액 ml = 물 ml × c / (100 - c)이다.
- 펌프 토출량은 근거가 있는 값만 사용한다. 정수 펌프 횟수와 남은 별도 계량량을 안내하고, 임의의 반 펌프나 반올림을 가정하지 않는다.
- 제품 검색어와 저장 제품명을 구분하고, 판매 옵션·사용 방법 미선택과 정량 캡슐의 비례 환산 제한을 확인한다.
- Todo 변경은 초기 상태, 최종 결정, 이유, 관련 커밋 또는 테스트 파일을 연결해 설명한다. 기록에 없는 테스트 수행이나 당시의 동기를 꾸며 쓰지 않는다.
- npm test와 npm run build를 실행해 결과를 기록한다. PostgreSQL 통합 테스트, 실기기 패스키, 운영 배포 검증은 실제 수행한 경우에만 통과로 적는다.
- 스킬의 이번 사용과 과거 사용을 구분한다. 개인 회고는 작성자 확인 전 초안으로 표시한다.
- GitHub 공개 상태와 push 이력은 별도로 확인한다. 공개 전환·커밋·푸시는 사용자가 승인한 범위에서 진행한다.
