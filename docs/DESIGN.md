# Design System

사용자가 요청한 흰색 배경, 검은색 글자, 심플하고 모던한 계산기.

## 승인된 디자인 기준

2026-10-16 사용자가 현재 구현된 디자인을 승인하고 이 문서를 프로젝트의 기준으로 지정했다.
이 문서는 `src/client/index.html`의 흰 배경과 검은 글자 중심 화면을 보존하고 확장하기 위한 디자인 계약이다.
이후 기능 추가와 오류 수정은 아래 규칙과 기존 컴포넌트를 따른다. 시각적 방향을 바꾸는 재디자인은 사용자의 명시적인 요청이 있을 때 진행한다.
문서와 구현이 어긋나면 승인된 화면의 실제 스타일을 먼저 확인한다. 새로운 요소도 같은 색상, 글자 크기, 간격, 모서리와 상태 표현을 사용한다.

## Layout

최대 너비 720px의 한 열 구성. 물 용량 → 희석 설정(희석비율 또는 농도) → 넣을 원액 → 저장한 비율 순서로 읽는다.
데스크톱 좌우 패널과 중첩 카드를 사용하지 않는다. 구역은 여백과 1px 구분선으로 나눈다.
모바일 좌우 여백은 20px, 데스크톱은 28px. 빠른 선택은 데스크톱 8열, 모바일 4열이다.

600px 이하에서 모바일 배치를 적용한다. 페이지 패딩은 데스크톱 `48px 28px 64px`, 모바일 `28px 20px 40px`이다.
계산 구역 사이는 데스크톱 28px, 모바일 24px을 띄운다. 제목과 조작부 사이는 12px, 연관 요소 사이는 6–10px을 사용한다.
부가 기능은 결과 아래나 페이지 하단에 배치하며, 설명이 길면 기존 details 패턴으로 접어서 제공한다.

## Type and color

Pretendard와 시스템 산세리프를 사용한다. 결과는 64px, 모바일은 56px이며 숫자는 tabular-nums를 적용한다.
본문은 #171717, 보조 설명은 #525252 또는 #626262. 흰 바탕 위에서 읽을 수 있는 대비를 유지한다.
검은 채움은 선택한 비율과 저장 동작에만 사용한다. 오류에만 붉은색을 허용한다.
밝은 디자인을 고정하며 운영체제 다크 모드에서도 색상을 유지한다.

제목은 700, 구역 제목은 650, 결과와 입력 숫자는 600 굵기를 사용한다. 본문 줄 높이는 1.5이다.
페이지 제목 자간은 -0.03em, 구역 제목은 -0.02em, 결과 숫자는 -0.04em이다.
브랜드 아이콘은 20px 단색 물방울이며, 조작 아이콘은 같은 두께의 단순한 선으로 표현한다.

## Controls and states

희석 설정은 기존 단위 버튼 스타일로 희석비율/농도(%) 입력 방식을 전환한다.
농도는 완성액에서 원액의 부피 비율이며 입력창 아래 12px 보조 문구로 설명한다.
0 이하, 100 이상 또는 빈 농도는 오류 문구와 빈 결과를 표시하고 복사·저장을 비활성화한다.

입력창은 1px 테두리와 8px 모서리, 작은 버튼은 6px 모서리를 사용한다.
빠른 선택의 활성 상태는 검은 배경과 흰 글자로 표시한다.
포커스는 검은 2px 외곽선으로 표시한다. 기본 버튼, 호버, 폼 오류, 빈 목록, 토스트를 지원한다.
계량컵과 펌프 환산은 기본 접힌 details로 제공한다.
저장 목록은 행과 구분선으로 구성하며 수정·삭제 버튼을 유지한다.
reduced-motion 설정에서는 전환 효과를 끈다.

홈 화면 설치와 오프라인 안내는 페이지 하단의 접힌 details로 제공한다.
설치 버튼은 기존 검은색 기본 버튼을 재사용하고 브라우저가 설치 프롬프트를 제공할 때 표시한다.
준비 상태 문구는 13px 보조 글자색을 사용한다.

## 재사용할 컴포넌트

펌프 1회 토출량은 기존 숫자 입력 스타일을 사용하고, 횟수는 결과 바로 아래 16px·600 굵기로 표시한다.
제품별 펌프 설정은 프리셋 폼의 선택 입력으로 제공한다. 정수 펌프 횟수와 별도 계량할 나머지를 명시한다.
패스키 보관함도 접힌 details로 제공한다. 목록 선택·충돌·복구 상태는 기존 글자와 버튼으로 안내하며 새 강조색이나 배지를 추가하지 않는다.

- 숫자 입력: 54px 높이, 1px `input-border` 테두리, 8px 모서리, 오른쪽 정렬 숫자와 단위. 증감 버튼은 48px 너비이며 입력창과 8px 간격을 둔다.
- 빠른 선택: 최소 44px 높이, 6px 모서리, 기본 흰 배경과 얇은 테두리. 선택한 항목은 검은 배경과 흰 글자로 표시한다.
- 입력 방식 전환: 회색 배경과 굵은 글자로 활성 항목을 표시한다. 희석 설정 전환 버튼은 최소 44px 높이이다.
- 기본 동작: 검은 배경, 흰 글자, 최소 44px 높이, 6px 모서리. 호버는 `primary-hover`, 비활성은 불투명도 0.4이다.
- 보조 동작: 회색 글자와 투명 배경, 호버에 옅은 회색 배경. 수정·삭제 아이콘 버튼은 44px 정사각형이다.
- 저장 목록: 카드 대신 가로 구분선이 있는 행. 이름 14px, 메타 정보 12px, 용도 11px. 모바일에서는 긴 이름을 줄바꿈한다.
- 알림: 하단 중앙의 검은 토스트에 흰 13px 글자. 8px 모서리, 좌우 화면 여백 최소 16px을 유지한다.

## 기능 확장 시 유지할 원칙

- 새 색상이나 글꼴을 추가하기 전에 위 팔레트와 글자 체계를 재사용한다.
- 그라디언트, 유리 효과, 네온, 장식용 그림자, 상태 배지, 중첩 카드, 대시보드식 다단 패널을 추가하지 않는다.
- 강조는 글자 크기·굵기·여백·선택 상태로 표현한다. 설명과 보조 수치는 결과 숫자보다 시각적 우선순위를 낮춘다.
- 포커스, 오류, 비활성, 빈 목록을 함께 구현하고 모바일에서 긴 한글 문구와 숫자가 넘치지 않게 확인한다.
- 변경 작업 전후 스크린샷을 사용자에게 제공한다. 완료 후 커밋·푸시 여부를 확인한다.
- 제품 검색어와 저장할 케미컬 이름은 각각의 라벨이 있는 입력으로 분리한다. 카탈로그 선택 시 실제 제품명을 이름 입력에 표시하고, 선택된 이름은 읽기 전용으로 유지하며 ‘직접 입력으로 전환’ 동작으로 수정할 수 있게 한다. 검색 결과와 선택 설정은 기존 한 열 구성·구분선·입력 스타일을 사용한다.
